# Espaço Astrolábio

Site institucional estático para `espacoastrolabioloja.com.br`.

## Prévia local

Sirva esta pasta com um servidor HTTP local e abra `index.html` pelo endereço exibido.

## Publicação

O projeto não depende de compilação. A publicação oficial usa GitHub Pages com o domínio `espacoastrolabioloja.com.br` declarado em `CNAME`.
